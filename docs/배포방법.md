# 배포 방법 (GitHub Pages)

이 문서는 photofolio를 GitHub Pages로 배포하기 위해 적용한 설정과, 평소 배포 절차를 정리한다.

- **배포 주소**: https://0625chopin.github.io/my-profile-site/
- **저장소**: https://github.com/0625chopin/my-profile-site
- **배포 방식**: GitHub Actions — `main` 브랜치 푸시 시 자동 빌드·배포

## 1. 적용된 설정

### 1-1. Vite base 경로 (`vite.config.ts`)

GitHub Pages는 `https://<사용자>.github.io/<저장소이름>/` 하위 경로에서 사이트를 서빙하므로,
번들 자산 경로 앞에 저장소 이름을 붙이도록 `base`를 지정했다.

```ts
export default defineConfig({
  base: '/my-profile-site/',
  plugins: [react()],
})
```

> 이 설정이 없으면 JS/CSS가 도메인 루트(`/assets/...`)에서 로드를 시도해 404가 발생한다.

### 1-2. 배포 워크플로 (`.github/workflows/deploy.yml`)

`main` 푸시(또는 수동 실행) 시 두 단계로 동작한다.

| 잡 | 하는 일 |
|---|---|
| `build` | 체크아웃 → Node 22 설치(npm 캐시) → `npm ci` → `npm run build`(타입체크+번들링) → `dist/`를 Pages 아티팩트로 업로드 |
| `deploy` | 업로드된 아티팩트를 GitHub Pages에 배포 |

트리거:

- `push`: `main` 브랜치 푸시 시 자동 실행
- `workflow_dispatch`: Actions 탭에서 수동 실행 가능

### 1-3. 저장소 Pages 설정 (1회, 웹 UI)

**Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택해야 한다.

> ⚠️ **주의 — "Deploy from a branch"를 선택하면 안 된다.**
> 브랜치 모드는 빌드 결과물이 아니라 **저장소 소스 파일을 그대로** 서빙하므로,
> 브라우저에서 `/src/main.tsx` 404 에러가 나며 빈 화면이 표시된다.
> 실제로 초기 설정 시 이 문제를 겪었고, Source를 GitHub Actions로 바꿔 해결했다.

## 2. 평소 배포 절차

별도 작업이 필요 없다. `main`에 푸시하면 자동으로 배포된다.

```bash
git add <변경 파일>
git commit -m "변경 내용"
git push
```

푸시 후 1분 내외로 배포가 완료된다.

### 수동 재배포

코드 변경 없이 다시 배포하려면 둘 중 하나를 사용한다.

1. **Actions 탭** → "Deploy to GitHub Pages" → **Run workflow** 버튼
2. 빈 커밋 푸시:

   ```bash
   git commit --allow-empty -m "배포 재실행"
   git push
   ```

## 3. 배포 확인

1. [Actions 탭](https://github.com/0625chopin/my-profile-site/actions)에서 워크플로가 초록색(성공)인지 확인
2. https://0625chopin.github.io/my-profile-site/ 접속
3. 빌드 결과물이 서빙되는지 확인하려면 페이지 소스에서 다음 형태의 스크립트 태그를 확인:

   ```html
   <script type="module" crossorigin src="/my-profile-site/assets/index-XXXX.js"></script>
   ```

   `<script src="/src/main.tsx">`가 보이면 소스 원본이 서빙되는 것 — Pages Source 설정(1-3)을 다시 확인한다.

## 4. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 빈 화면 + `/src/main.tsx` 404 | Pages Source가 "Deploy from a branch"로 설정됨 | Source를 **GitHub Actions**로 변경 후 재배포 |
| JS/CSS 404 (`/assets/...`) | `vite.config.ts`의 `base` 누락·오타 | `base: '/my-profile-site/'` 확인 |
| 워크플로 실패 (`configure-pages` 단계) | 저장소에서 Pages가 아직 활성화되지 않음 | Settings → Pages에서 Source 선택 후 Re-run jobs |
| 빌드 실패 | `tsc -b` 타입 에러 또는 `vite build` 에러 | 로컬에서 `npm run build`로 재현 후 수정 |
| 푸시했는데 변경이 안 보임 | 배포 진행 중이거나 브라우저 캐시 | Actions 완료 대기 후 강력 새로고침(Ctrl+F5) |
